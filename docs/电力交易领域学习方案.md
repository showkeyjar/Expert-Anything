**当前短板（2026-09-23 回填：括号内为现状）**：

## 三、快速上手路径设计

### 3.1 用户画像识别

```python
# 在 learner.py 中新增

def detect_user_profile(state: dict) -> dict:
    """识别用户背景，推荐个性化学习路径"""
    
    # 从历史记录推断
    history = state.get("learning_history", [])
    assets = state.get("assets", {})
    
    # 检查是否有关键领域标记
    domain_hint = None
    for asset_id, asset in assets.items():
        title = asset.get("title", "")
        if "电力" in title or "market" in title.lower():
            domain_hint = "electricity"
            break
    
    # 根据领域推荐路径
    paths = {
        "electricity": {
            "quick_start": ["两级市场架构", "参与主体", "电价机制"],
            "deep_dive": ["交易流程", "LMP定价", "不平衡资金处理"],
            "practice": ["模拟日前市场出清", "计算节点边际电价"]
        },
        "default": {
            "quick_start": ["核心概念", "基本架构"],
            "deep_dive": ["进阶概念", "案例分析"]
        }
    }
    
    return paths.get(domain_hint, paths["default"])
```

### 3.2 术语对照表生成

```python
# 文件：expert_anything/core/terminology.py

def generate_glossary(asset: KnowledgeAsset) -> list[dict]:
    """为资产生成术语对照表"""
    
    glossary = []
    for concept in asset.concepts:
        glossary.append({
            "term": concept.name,
            "definition": concept.definition[:100] + "..." if len(concept.definition) > 100 else concept.definition,
            "chapter": concept.chapter,
            "evidence_count": len(concept.evidence),
            "relations": len([r for r in asset.relations 
                            if r.source == concept.id or r.target == concept.id])
        })
    
    # 按章节分组
    by_chapter = {}
    for item in glossary:
        ch = item["chapter"] or "未分类"
        by_chapter.setdefault(ch, []).append(item)
    
    return by_chapter
```

### 7.2 ID 映射机制的最终形态：归一化名称 + 括号别名

- **两个 ID 空间永不对齐**：模板概念 ID（`et-*`）与资产概念 ID（`c*`）只通过**名称**建立映射，
  避免模板改写抽取产物的 ID 语义。
- **归一化**：`_normalize_name`（NFKC → 小写 → 折叠空白与分隔符 → 去标点）与 `learner.normalize` 同源，
  保证"归一化名称"在映射、掌握度、复习队列中的语义一致。
- **括号别名**：`concept_name_variants` 对「节点边际电价(LMP)」同时产出全称、去括号名、括号内别名
  （别名须 ≥2 字符，避免单字母误配），并叠加模板概念声明的 `aliases`；变体按长度降序匹配，
  **全称优先于别名**，每个资产概念最多被认领一次。
- **不静默丢弃**：未命中的模板概念如实进入 `unmatched`；`build_concept_mapping` 可干跑（不改动资产）。
- **三路解析**：`resolve_template_concept_id` 支持 模板 ID → 资产 ID → 概念名（任意变体拼写），
  解码器侧 `get_scene_for_concept` 复用同一解析，因此 `et-001` / `c001` / `两级市场架构` 指向同一场景。
- **映射失败即降级、保留原学习路径**：映射为空或覆盖率 < `DEFAULT_MIN_COVERAGE`（0.5）时，
  `learning_path_applied=False`，`reason` 取 `degraded_no_mapping` / `degraded_low_coverage` /
  `unknown_domain`，**资产原有学习路径原样保留**；改写路径前每个 ID 都回查 `asset.concepts`，杜绝悬空引用。
- **来源约束优先**：模板只在 `definition` / `evidence` 为空时补文本，已抽取的来源约束内容永不被覆盖
  （与 `AGENTS.md` 设计理念第 15 条一致）。
